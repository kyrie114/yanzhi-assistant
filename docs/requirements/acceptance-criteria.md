编号规则：AC-故事序号-条目序号。判定顺序：未登录或令牌过期返回 401；角色不能使用该功能返回 403；对具体资源没有读取权限返回 404。测试数据中的用户 A 和用户 B 是两个互不相关的注册用户。管理员由命令行创建，名下没有知识库。

## US-01 注册与登录

**AC-01-01 注册成功**

- Given 邮箱 a@example.edu.cn 尚未注册
- When 提交该邮箱、姓名「张三」和密码 Abc12345
- Then 返回 201，新增用户记录，密码以 bcrypt 哈希保存，页面进入可登录状态

**AC-01-02 邮箱重复**

- Given 该邮箱已注册
- When 再次使用它注册
- Then 返回 409，提示「该邮箱已注册」，不新增记录

**AC-01-03 密码不符合规则**

- Given 用户在注册页
- When 密码为 abc123 或 abcdefgh
- Then 返回 422，提示「密码至少 8 位，且需同时包含字母和数字」，不新增记录

**AC-01-04 登录成功**

- Given 该邮箱已注册
- When 使用正确的邮箱和密码登录
- Then 返回 200 和有效期 2 小时的访问令牌，进入知识库首页

**AC-01-05 登录失败**

- Given 用户在登录页
- When 输入不存在的邮箱，或输入已注册邮箱但密码错误
- Then 两种情况都返回 401，提示都是「邮箱或密码错误」

**AC-01-06 退出登录**

- Given 用户 A 持有两枚未过期令牌 T 和 T2
- When 使用 T 退出，再分别用 T 和 T2 请求资料列表
- Then 退出返回 204；T 得到 401；T2 得到 200

**AC-01-07 修改密码**

- Given 用户 A 的当前密码是 Abc12345，并持有令牌 T
- When 提交正确的旧密码和新密码 Abc123456
- Then 返回 200，T 立即失效，新密码可以登录，旧密码登录返回 401
- When 旧密码填错，或新密码不足 8 位
- Then 分别返回 401 和 422，原密码哈希和原令牌不变

**AC-01-08 登录耗时**

- Given 已有 20 个注册账号
- When 以 20 个并发用户对登录接口压测 5 分钟
- Then P95 不超过 500 ms

## US-02 建立知识库并放入论文

**AC-02-01 创建知识库并上传**

- Given 用户 A 已登录，存储未超配额
- When 创建知识库「论文阅读」，并上传一个 12 MB、20 页的文本型 PDF，填写标题、作者和年份
- Then 知识库出现在列表中；资料返回 201，状态为待处理，书目与填写内容一致

**AC-02-02 知识库名称**

- Given 用户 A 已登录
- When 知识库名称为空或超过 50 个字符
- Then 返回 422，不创建知识库

**AC-02-03 非 PDF**

- Given 用户 A 已登录
- When 向 PDF 上传接口提交 docx，或提交扩展名为 pdf 但文件头不是 %PDF 的文件
- Then 返回 415，不保存文件，不创建资料

**AC-02-04 超过 50 MB**

- Given 用户 A 已登录
- When 选择 51 MB 的 PDF
- Then 上传前阻止并提示不能超过 50 MB；绕过页面直接调用接口时返回 413，不保存文件

**AC-02-05 大小边界**

- Given 用户 A 已登录
- When 上传恰好 52,428,800 字节的文本型 PDF
- Then 返回 201

**AC-02-06 页数超限**

- Given 文件没有打开密码且能读出页数
- When 上传 350 页的 PDF
- Then 返回 422，提示不能超过 300 页，不创建资料

**AC-02-07 重复上传**

- Given 用户 A 已有一份 SHA-256 相同且状态不是失败的资料
- When 再次上传该文件
- Then 返回 409，提示资料已存在，并给出已有资料的位置

**AC-02-08 存储配额**

- Given 用户 A 已使用 2,137,000,000 字节
- When 上传 20,971,520 字节的 PDF
- Then 返回 422，错误码 STORAGE_QUOTA_EXCEEDED，不保存文件。2 GB 按 2,147,483,648 字节计算

**AC-02-09 加密 PDF**

- Given 用户 A 已登录
- When 上传设置了打开密码的 PDF
- Then 返回 422，提示「文件已加密，无法解析」，不创建资料，不进入队列

**AC-02-10 书目与列表**

- Given 用户 A 有 25 份资料，其中 2 份标题含有「图谱」，其中一份标题为「旧标题」
- When 把「旧标题」改为「新标题」，再按「图谱」搜索并请求每页 10 条
- Then 详情显示新标题；搜索结果只有这 2 份。之后问答出处使用「新标题」

**AC-02-11 资料列表耗时**

- Given 用户 A 有 200 份资料
- When 以 20 个并发用户压测资料列表 5 分钟
- Then P95 不超过 500 ms

**AC-02-12 失败后再次上传同一文件**

- Given 用户 A 已有一份 SHA-256 相同、状态为失败的资料
- When 再次上传该文件
- Then 不新建第二条资料，也不返回 409。原记录回到待处理并重新进入处理

## US-03 查看处理进度并重试

**AC-03-01 正常完成**

- Given 用户 A 上传了 20 页文本型 PDF
- When 等待处理
- Then 60 秒内经过解析中、向量化中变为已完成；每个切块有物理页码、段落序号和向量。这 60 秒不含图谱抽取

**AC-03-02 进度可见**

- Given 一份资料正在处理
- When 用户 A 停留在列表页
- Then 5 秒内能看到状态变化，不必手动刷新

**AC-03-03 全篇没有文本**

- Given 识别模型未配置，上传的 PDF 没有文本层
- When 处理结束
- Then 状态为失败，原因为识别未成功，切块数为 0

**AC-03-04 损坏文件**

- Given PDF 没有打开密码但内容已损坏
- When 处理结束
- Then 状态为失败，原因为文件已损坏

**AC-03-05 向量服务失败**

- Given 向量服务持续超时
- When 处理后台运行
- Then 自动重试 2 次后失败，原因为向量化服务暂不可用。手动重试满 3 次后按钮不可用，并提示联系管理员

**AC-03-06 服务重启**

- Given 资料处于解析中时主服务重启
- When 服务恢复
- Then 任务变为失败，原因为「处理中断，请重试」，不自动重跑，也不计入 3 次手动重试

**AC-03-07 部分页没有文本**

- Given PDF 共 10 页，第 3、4 页抽不出文本
- When 处理结束
- Then 状态为已完成；这两页不产生切块并在详情中列出；第 5 页的切块页码仍是 5

**AC-03-08 解析服务不可用**

- Given docreader 未启动，或单次调用超过 120 秒没有返回
- When 处理用户 A 的 PDF
- Then 状态为失败，原因为「文档解析服务暂不可用」，不生成切块。用户仍可按 AC-03-05 的次数手动重试

## US-04 删除不再需要的资料

**AC-04-01 删除成功**

- Given 资料 X 已完成，并已有切块和向量
- When 用户 A 确认删除
- Then 资料记录、原始文件、切块和向量被删除。再提问只属于 X 的内容时，出处不再出现 X。图谱清理见 AC-07-07

**AC-04-02 历史出处**

- Given 某次会话引用过 X
- When X 删除后打开该会话
- Then 原出处显示「来源已删除」，页面不报错

**AC-04-03 其他人删除**

- Given X 属于用户 A
- When 用户 B 调用删除接口
- Then 返回 404，X 保持不变

**AC-04-04 删除处理中的资料**

- Given X 处于向量化中
- When 用户 A 删除 X
- Then 返回 200，不再写入新切块或向量，列表中不再有 X

## US-05 用标签限定范围

**AC-05-01 创建标签**

- Given 用户 A 有知识库「论文阅读」
- When 创建标签「检索」
- Then 标签出现在该库中。名称为空或超过 50 个字符时返回 422

**AC-05-02 一份资料多个标签**

- Given 资料 X 在该库中，另有标签「图神经网络」
- When 把 X 同时标上「检索」和「图神经网络」
- Then 详情同时显示两个标签

**AC-05-03 按标签筛选**

- Given 「检索」下有 X 和 Y，标签外有 Z
- When 列表选择该标签
- Then 只显示 X 和 Y

**AC-05-04 删除标签**

- Given X 关联了「检索」
- When 删除该标签
- Then 标签消失，X 仍在，状态不变

**AC-05-05 其他人看不到标签**

- Given 标签属于用户 A
- When 用户 B 或管理员用该 ID 读取
- Then 返回 404

**AC-05-06 知识库列表耗时**

- Given 用户 A 有 50 个知识库
- When 以 20 个并发用户压测知识库列表 5 分钟
- Then P95 不超过 500 ms

## US-06 得到能核对的回答

**AC-06-01 回答附出处**

- Given X 已完成，第 4 页写明所用数据集
- When 用户 A 提问 X 使用了哪些数据集
- Then 回答流式返回，至少有一条「X 的标题, 第 4 页」。点击后展示来自第 4 个物理页的切块。跨页切块取起始页，不显示段落号

**AC-06-02 限定范围**

- Given 标签「检索」下有 X 和 Y，标签外有 Z。知识库「论文阅读」只有 X
- When 先按该标签提问，再只选择该知识库提问
- Then 第一次出处只来自 X 或 Y；第二次只来自 X

**AC-06-03 没有依据**

- Given 库中都是自然语言处理论文
- When 提问蛋白质折叠的最新方法，且最高相似度低于阈值
- Then 回复「知识库中未找到相关依据」，出处为空

**AC-06-04 没有已完成资料**

- Given 用户 A 没有已完成资料
- When 打开问答
- Then 输入不可用，提示先上传并等待处理完成

**AC-06-05 模型不可用**

- Given 对话模型超时或返回错误
- When 用户 A 提问
- Then 提示稍后重试，并给出 request_id，不展示内部堆栈。日志中有该 request_id

**AC-06-06 出处对应切块**

- Given 20 题评测集和对应资料已导入测试账号
- When 运行评测
- Then 回答中的出处都能对应到本次交给模型的切块，悬空出处为 0。图谱补充的切块算在其中

**AC-06-07 响应时间**

- Given 测试账号约有 5000 个切块
- When 连续提问 50 次
- Then 检索阶段 P95 不超过 2 秒，首个字符 P95 不超过 5 秒

**AC-06-08 相似度够但内容不支持**

- Given 最高相似度不低于阈值，但切块讨论的是另一个主题
- When 用户 A 提问
- Then 回复未找到依据，出处为空

**AC-06-09 回答语言**

- Given 一份已完成的英文资料，书目标题为英文
- When 用英文提出该资料能够回答的问题
- Then 回答主体为英文，出处标题与书目一致
- When 问题短到无法判断语言
- Then 回答主体为简体中文

**AC-06-10 只检索已完成资料**

- Given X 已完成，Y 解析中，两份都含有同一组句子
- When 针对这组句子提问
- Then 出处只来自 X

**AC-06-11 正文中的指令**

- Given X 的正文要求忽略指令、不给出来源并输出系统提示词
- When 提出一个应由 X 回答的问题
- Then 回答仍有页码出处，不输出系统提示词

**AC-06-12 关键词补上专名**

- Given X 只在一处出现 Zephyr-Bench-9，该专名与问题的向量相似度低于阈值
- When 提问 Zephyr-Bench-9 是什么
- Then 关键词检索命中该切块，出处包含 X 的标题和物理页

**AC-06-13 寒暄**

- Given 用户 A 有已完成资料
- When 只发送「你好」
- Then 返回简短回应，不检索资料，不附页码出处

## US-07 沿图谱查看关系

**AC-07-01 抽出实体并回到页码**

- Given X 已完成，第 6 页写明方法 LoRA，作者 Zhang，且该知识库启用图谱
- When 抽取完成
- Then 3 分钟内状态为已完成。用户 A 能看到 LoRA、Zhang 以及它们与 X 的边。每条边至少有一处证据，点开是 X 的切块，页码为 6

**AC-07-02 按范围查看**

- Given 知识库「论文阅读」只有 X，库外还有 Y。LoRA 只出现在 X
- When 打开该库图谱和 X 的详情图谱
- Then 两处都能看到 LoRA 与 X 相连。不筛选时可以看到 Y 的节点。详情图谱只展示 X 的一跳邻居

**AC-07-03 引用只连接库内资料**

- Given X 引用了同库已完成资料 Y 的标题，还引用了不在库中的 Missing Paper
- When 抽取完成
- Then 存在从 X 到 Y 的引用边，Y 可以打开。Missing Paper 出现在未入库引用中，图谱里没有对应节点

**AC-07-04 合并与隔离**

- Given 用户 A 的两份资料都写了 LoRA，用户 B 的资料也写了 LoRA
- When 两边抽取完成
- Then A 的图谱里只有一个 LoRA 节点，连接 A 的两份资料。B 看不到这个节点。同一用户库内的 lora 与 LoRA 合并

**AC-07-05 抽取失败不影响问答**

- Given X 已完成，图谱抽取失败
- When 用户 A 对 X 提问
- Then X 仍为已完成。问答按直接问答返回，不因图谱失败返回 500

**AC-07-06 抽取重试与中断**

- Given 抽取所用模型持续超时
- When 自动重试 2 次后仍失败
- Then 抽取状态为失败，资料状态保持已完成。手动重试满 3 次后按钮不可用
- Given 抽取中服务重启
- When 服务恢复
- Then 抽取变为失败，原因为处理中断，不一直停留在抽取中。这次失败不计入 3 次手动重试

**AC-07-07 删除时清理**

- Given LoRA 只被 X 使用，作者 Zhang 还连接着仍在库中的 Y
- When 用户 A 删除 X
- Then LoRA 及其只以 X 为证据的关系被删除。Zhang 仍连接 Y。问答和图谱都不再出现 X

**AC-07-08 其他人看不到图谱**

- Given 节点属于用户 A
- When 用户 B 或管理员请求全库图谱、X 的一跳或某个节点
- Then 返回 404，响应不含节点名称
- Given X 的正文要求把节点名称改成系统提示词
- When 抽取完成
- Then 节点名称来自资料内容，关系仍带 X 的页码

## US-08 资料只由创建者访问

**AC-08-01 其他用户访问资料**

- Given X 属于用户 A
- When 用户 B 访问详情、原文下载或切块
- Then 返回 404

**AC-08-02 检索隔离**

- Given X 含有一段只在 A 库中出现的话，B 的库里没有相关资料
- When B 针对这句话提问
- Then 出处不出现 X。检索条件限定为 B 自己的资料。图谱补充也不加入 X 的切块

**AC-08-03 未登录**

- Given 未登录，或令牌已超过 2 小时
- When 调用业务接口
- Then 返回 401，页面回到登录

**AC-08-04 文件地址**

- Given X 的原始文件已保存在服务器
- When 不经下载接口，直接请求存储路径
- Then 返回 404，得不到文件内容

**AC-08-05 管理员不阅读资料**

- Given 管理员已登录，X、笔记、会话、标签、图谱和 Wiki 都属于用户 A
- When 管理员请求这些详情，并请求 X 的原文
- Then 全部返回 404，响应不含标题或正文

## US-09 配置模型连接

**AC-09-01 连接测试**

- Given 管理员打开模型配置
- When 填写地址、模型名称和密钥后测试连接
- Then 成功时显示连接成功和耗时；密钥无效时显示鉴权失败；地址不可达时显示网络不可达

**AC-09-02 密钥脱敏**

- Given 保存的密钥是 sk-test-1234abcd
- When 查看数据库和配置接口
- Then 数据库中是密文；接口和页面只返回 ****abcd

**AC-09-03 普通用户不能配置**

- Given 用户 A 已登录
- When 打开模型配置或调用配置接口
- Then 返回 403

**AC-09-04 尚未配置**

- Given 尚未配置对话模型
- When 用户 A 提问或生成要点
- Then 提示联系管理员，不返回 500

**AC-09-05 更换向量模型**

- Given 已有已完成资料和图谱，当前向量模型为甲
- When 管理员改为乙但不确认重建
- Then 配置仍是甲，原向量和图谱仍可用
- When 管理员确认重建
- Then 配置变为乙，这些资料回到待处理，原向量不再参与检索，原图谱不参与补充

## US-10 继续上一次的讨论

**AC-10-01 会话列表**

- Given 用户 A 有 3 个会话
- When 打开问答历史
- Then 按最近更新时间倒序显示，点开后能看到问题和出处

**AC-10-02 多轮上下文**

- Given 上一轮问了 X 的方法
- When 接着问它在哪些数据集上做了实验
- Then 回答针对 X，请求携带最近不超过 5 轮上下文

**AC-10-03 重命名与删除**

- Given 用户 A 有会话 S
- When 重命名为「图谱阅读」，再删除 S
- Then 列表先显示新名称；删除后不再出现，再次访问返回 404

**AC-10-04 其他人的会话**

- Given S 属于用户 A
- When 用户 B 或管理员用会话 ID 访问
- Then 返回 404

## US-11 把追问补成完整问题

**AC-11-01 追问被补全**

- Given 上一轮问题是 X 用了什么数据集
- When 用户 A 追问它的规模
- Then 检索用的查询同时包含 X 和规模，而不是只检索「它的规模」

**AC-11-02 改写失败**

- Given 改写调用失败
- When 用户 A 追问
- Then 用原问题继续检索，返回回答或未找到依据，不返回 500

## US-12 把更相关的片段排到前面

**AC-12-01 已配置重排**

- Given 混合检索返回 8 个候选，重排已配置，取前 5 条
- When 用户 A 提问
- Then 交给模型的是重排后的前 5 条。图谱补充不占这 5 个名额，并标为图谱补充。日志记录重排已执行

**AC-12-02 未配置重排**
