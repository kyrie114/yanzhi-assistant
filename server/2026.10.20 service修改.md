# FR-01 账户后端运行说明

当前可运行范围是注册、登录、读取本人资料、退出和修改密码的 HTTP API。账户逻辑与路由原先已有；`cmd/server` 将它们连接成可启动的服务。启动命令使用 **内存存储**，需要显式选择，重启会丢失用户、密码变更及退出令牌记录。它不连接 PostgreSQL，不提供邮件验证、登录页面或跨进程会话共享。

## 本地启动

需要满足 `go.mod` 要求的 Go 工具链。在本目录的 PowerShell 中运行：

```powershell
# 每次演示生成随机密钥；实际运行应从安全的配置来源设置并妥善保管。
$secretBytes = New-Object byte[] 32
[System.Security.Cryptography.RandomNumberGenerator]::Fill($secretBytes)
$env:JWT_SECRET = [Convert]::ToBase64String($secretBytes)
go run ./cmd/server --in-memory
```

也可设置 `$env:ACCOUNT_STORE = "memory"` 后运行 `go run ./cmd/server`。缺少显式内存存储选择、缺少密钥、密钥不足 32 字节或全部为空白时，启动失败。

| 配置项             | 默认值／要求                               |
| --------------- | ------------------------------------ |
| `ACCOUNT_STORE` | 只支持 `memory`；与 `--in-memory` 二选一显式启用 |
| `JWT_SECRET`    | 必填                                   |
| `HTTP_ADDR`     | `127.0.0.1:8080`；格式为 `host:port`     |
| `BCRYPT_COST`   | `10`；可设置整数 `4`–`31`，较高值会显著增加计算时间     |

默认只监听本机。修改 `HTTP_ADDR` 前应考虑部署环境；本示例直接提供 HTTP。按 Ctrl+C 后服务停止接收新连接，并给在途请求最多 5 秒的退出时间。服务设置了请求头、读写及空闲连接超时。

## 接口

JSON 请求使用 `Content-Type: application/json`。受保护接口使用 `Authorization: Bearer <access_token>`。

| 方法与路径                        | 请求字段／用途                                     | 成功状态  |
| ---------------------------- | ------------------------------------------- | ----- |
| `POST /api/v1/auth/register` | `email`、`name`、`password`                   | `201` |
| `POST /api/v1/auth/login`    | `email`、`password`；返回 `access_token`        | `200` |
| `GET /api/v1/me`             | 读取当前用户资料，需要令牌                               | `200` |
| `POST /api/v1/auth/logout`   | 使当前令牌失效，需要令牌                                | `204` |
| `POST /api/v1/auth/password` | `old_password`、`new_password`，需要令牌；成功后需重新登录 | `200` |
| `GET /api/v1/documents`      | 仅用于认证验收，需要令牌；当前返回空列表占位                      | `200` |

注册默认角色为 `user`，密码至少 8 个字符并同时包含字母和数字。重复邮箱返回 `409`；不合法字段或弱密码返回 `422`；无效凭据、过期或已失效令牌返回 `401`。登录令牌有效期为 2 小时。退出只作废当前令牌，修改密码会使此前签发的所有令牌失效。

## 验证

```powershell
go test -count=1 -v ./cmd/server ./internal/account ./internal/httpapi
go test -count=1 ./...
go vet ./...
```

入口测试覆盖非法启动配置、默认配置、真实本地 TCP 请求链路（注册→登录→本人资料→退出→修改密码→重新登录）、关闭后不再接受连接，以及在途请求的正常完成。测试中的 bcrypt 成本为 4，以便快速验证；运行默认值仍为 10。最终执行输出与通过情况见 `homework` 中本次开发记录。
